# 展览板二维码内容页

## 目标
- 展览板上放 6 个二维码
- 微信扫描后可直接看到对应内容
- 页面尽量轻量，打开快、不卡顿
- 方案可免费长期部署

## 实现方式
- 使用纯静态 HTML 页面
- 每个二维码对应一个独立页面
- 入口页面统一展示 6 个二维码入口
- 部署到 GitHub Pages、Netlify 或 Vercel 均可

## 目录说明
- index.html：总入口页
- pages/page-01.html ~ page-06.html：6 个内容页

## 推荐部署
### GitHub Pages
1. 在 GitHub 新建仓库
2. 将当前文件上传到仓库
3. 打开仓库设置 → Pages
4. 选择部署分支为 main，根目录为 /root
5. 访问 `https://你的用户名.github.io/仓库名/`

## 后续可扩展
- 把内容页替换成图片、视频、PDF 预览
- 生成真正的二维码图片并替换 pages/qr-*.png
- 在页面中加入统计分析或跳转埋点
